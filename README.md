## LevelUp - Bubble Level for Android 📐

Простой, точный и полностью офлайн-инструмент, который превращает ваш смартфон в строительный уровень. Больше не нужно искать пузырьковый уровень, чтобы ровно повесить полку или картину!

### ✨ Особенности
- **Точность:** Измерение наклона по осям X и Y в реальном времени.
- **Визуальная индикация:** Крупный угол наклона меняет цвет (Зеленый = ровно, Оранжевый = почти, Красный = наклон).
- **Экономия батареи:** Датчик автоматически отключается при сворачивании приложения.
- **100% Офлайн:** Работает без интернета и не требует никаких разрешений (кроме доступа к датчикам).

### 🛠 Технологии
- C# / .NET 8
- .NET MAUI
- Акселерометр Android

### 📲 Установка
1. Скачайте файл `.apk` из раздела **Assets** ниже.
2. Разрешите установку из неизвестных источников на вашем Android-устройстве.
3. Откройте приложение, нажмите «Старт» и положите телефон на поверхность.
